# Orientações para o painel administrativo

- As funcionalidades do painel administrativo são destinadas à interface web para desktop, não à visualização mobile do painel.
- Não crie nem execute testes para a visualização mobile do painel administrativo e não verifique sua aparência em dispositivos móveis.
- Essa orientação não remove a prévia mobile do aplicativo disponível nos editores do painel.
